The upstream files did not carry per-file copyright headers. The GPL notice at the top of each
Java file was added when vendoring, and names Zrp200 as the copyright holder.

Local changes from that commit, all in ScrollOfDebug.java:
- handleDebug() follows this fork's debug-run stamp
  (ShatteredPixelDungeon.debugSession && Dungeon.debugRun) instead of DeviceCompat.isDebug().
- doRead() and interpret() refuse to run unless that stamp is set.
- The class index is built on first use, not when the class is loaded.
- Item name, description chrome, and the command prompt come from messages properties.
  Command syntax text inside the tool stays in this file.
- reset() keeps the scroll-holder sprite and does not join the scroll rune table.
- value() and energyVal() are 0. The item is unique and its curse state is known.
